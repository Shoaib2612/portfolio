# shoaibabduljabbar.com

Personal portfolio of Shoaib Abdul Jabbar, Senior Software Engineer based in Dubai, UAE.

Built with Next.js, TypeScript and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Editing

All site text lives in `src/data/content.ts`. Images and the CV go in `public/`.
